# Property Price Prediction

## Overview
This project builds a regression model to predict property sale prices using housing features such as area, basement size, construction year, room count, quality scores, and neighborhood details.

## Problem
Property prices depend on many features, and estimating the right sale price is important for sellers, buyers, and investors. This project uses regression analysis to model those relationships and improve price prediction.

## What I Did
- Explored the dataset and studied missing values, target distribution, and feature correlations.
- Cleaned and preprocessed the data by treating missing values, handling outliers, and converting data types.
- Applied feature engineering, including target transformation, categorical encoding, feature selection, and scaling.
- Built and evaluated a regression model to predict property sale price.
- Reviewed performance metrics and feature importance to understand the results.

## Outcome
The project resulted in a complete regression-based property price prediction workflow. After preprocessing, feature engineering, and model training, the model was able to estimate sale prices and highlight the key drivers of property value. This provides a useful foundation for pricing analysis and future model improvement.

## Description
Regression-based property price prediction project using preprocessing, feature engineering, and model evaluation.
